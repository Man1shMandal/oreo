My ESP32 drops MQTT every ~10 min and never reconnects. What's wrong with my loop()?

Your loop() calls client.loop() but never checks client.connected(), so once the broker drops you, nothing reconnects. Add a non-blocking retry:

cppCopy
void loop() {
  if (!client.connected() && millis() - lastTry > 5000) {
    lastTry = millis();
    reconnect();   // re-subscribe inside here
  }
  client.loop();
}

Also raise the keep-alive with client.setKeepAlive(60). The default 15 s is tight on flaky Wi-Fi.
